# 🟠 Medium - Desafios de JavaScript

Esta pasta contém desafios classificados como **Medium**, focados em aprofundar a lógica de programação e explorar problemas que exigem maior capacidade de análise e planejamento utilizando JavaScript.

O objetivo desses exercícios é desenvolver habilidades como:

* implementação de algoritmos
* manipulação avançada de arrays e strings
* recursão
* orientação a objetos
* resolução de problemas mais complexos
* otimização e organização de código

Esses desafios representam um passo além dos níveis iniciais, exigindo mais atenção aos detalhes e à construção de soluções eficientes.
